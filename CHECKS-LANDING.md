## Що перевірено в браузері

Початкове відкриття головної; відсутність запиту до JSON до входу в каталог;
посилання шапки та CTA; активний пункт меню; Назад / Уперед; повернення на
головну через логотип; старий `#catalogue`; невідомий маршрут; назви вкладок
і `document.lang`; EN / УКР; збереження стану пошуку, міста, ризику, сортування
й розміру сторінки при навігації; правильний префікс `/Teneta/` для JSON;
відсутність зайвого повторного завантаження після повернення.

Також: 3 учасники й правильні фото; однорядне розташування на desktop;
круглі аватарки; підписи українською та англійською; один видимий h1 і main;
доступність меню на ширинах 320, 390, 640, 768, 1024, 1440, 1920 px;
відсутність горизонтального переповнення документа; горизонтальна прокрутка
самої таблиці на телефоні; робота головної незалежно від помилки даних;
повідомлення помилки й повторне завантаження каталогу; діалог запису та Escape;
експорт поточних результатів у JSON; порожній пошук і скидання фільтрів;
три рівні ризику та межі 65/85; відсутність синтетичних записів у таблиці
й експорті. Помилок JavaScript під час прогонів не зафіксовано.

## Середовище і межі доказів

Браузер запускав фактичні компоненти React із цього пакета, а не HTML-макет.
Використано React і ReactDOM 19.3.0 з наданої папки `node_modules`.
JSX перетворено TypeScript 5.8.3 в окремій офлайн-перевірочній збірці.
TypeScript не додається до проєкту і не є новою npm-залежністю користувача.

У браузерному прогоні відповіді JSON підставлені з наявного файлу, доступ до
сховища налаштувань підставлений тестовим об'єктом, а завантаження експорту
перехоплене для перевірки Blob і його вмісту. Це не перевірка реального backend
і не production-деплой. Hash-навігація й browser history перевірені нативно
в офлайн-документі. Стан сховища та його відмова додатково покриті Node-тестами.

Production-збірка Vite зупинилася до компіляції: у переданих Windows-залежностях
немає `@rolldown/binding-linux-x64-gnu`; npm-реєстр у цьому середовищі недоступний.
Тому перед PR слід виконати у своєму проєкті `npm run lint` та `npm run build`.
Ця помилка не є підставою видаляти чи перегенеровувати користувацький lockfile.

## Незмінені частини

Побайтово збережені: `package.json`, `package-lock.json`, `vite.config.js`,
`.github/workflows/deploy.yml`, `src/main.jsx`, `public/data/organizations.json`,
`src/services/organizationService.js`, `CatalogFilters.jsx`, `OrganizationTable.jsx`,
`RecordDialog.jsx`, `RiskBadge.jsx`, `RiskLegend.jsx`, `LanguageSwitcher.jsx`,
`src/SearchBar.css`, `src/index.css`. Відхилений пакет data-merge не застосований.

Фото в `src/assets/team` побайтово відповідають трьом вкладенням користувача.
Пакет не містить `.git`, `node_modules`, `dist`, `.env` або сторонніх облікових даних.
