# Teneta — головна сторінка та навігація

Оновлення для актуального фронтенду з архіву `Teneta.zip`, наданого 10.10.2026.
Це пакет змінених і нових файлів, не повний репозиторій. Стару копію колеги
та відхилений пакет `teneta-data-merge.zip` він не використовує.

## Встановлення

Збережи всі файли та перевір `git status`. Перед перемиканням гілок збережи
поточні незакомічені зміни окремим комітом або резервною копією.
Створи робочу гілку, наприклад `feat/landing-page`.

Розпакуй **вміст** ZIP у корінь актуального проєкту — поруч із `package.json`.
Об'єднай папки `src` і `tests`, замінивши включені файли. Не копіюй весь ZIP
усередину `src` і не застосовуй пакет до застарілої копії колеги.

Нових npm-залежностей немає. Не змінюй `.env`, конфігурацію Pages або workflow.
`public/data/organizations.json`, завантажувач даних, `package.json`, lockfile,
`vite.config.js`, `.github` та `main.jsx` збережені без змін.

```bash
node --test
npm run lint
npm run build
npm run dev
```

Відкрий кореневу адресу, яку показує Vite, з урахуванням `/Teneta/` у конфігурації.
Production-версію після успішної збірки можна перевірити через `npm run preview`.

## Поведінка

- `/Teneta/` та `/Teneta/#/` відкривають головну. Остання відвідана сторінка
  не зберігається як стартова.
- `/Teneta/#/catalogue` — пряме посилання на каталог. Його навмисне відкриття
  або оновлення залишається в каталозі. Старий `#catalogue` також підтримується.
- У шапці є Головна / Каталог і EN / УКР. Посилання видно й на вузьких екранах.
- Натискання на логотип повертає на головну. Назад / Уперед у браузері працюють.
- Головна містить логотип, опис, перехід до каталогу та команду
  `make kyiv great again`. Учасники з круглими аватарками стоять в одному рядку
  на широкому екрані, а на телефоні — компактною колонкою.
- Ролі: Повар Роман — frontend engineer; Панчук Юліана — team lead;
  Порошинська Мілана — backend engineer. Назви й ролі мають англійську
  та українську версії. Назва команди та гасло залишаються заданими.
- Пошук, фільтри, сортування й розмір сторінки зберігаються при переходах
  між сторінками в межах поточного відкриття сайту.
- JSON завантажується лише після першого переходу в каталог, а не на головній.
  Після завершеного завантаження звичайне повернення в каталог не повторює запит.
- Якщо запит було перервано виходом із каталогу, наступний вхід повторить його.
- Семантичні карти цим пакетом не реалізовані. У шапці немає неробочих посилань.

## Де редагувати

- `src/pages/LandingPage.jsx` — розмітка головної та відповідність фото учасникам.
- `src/pages/LandingPage.css` — стилі головної та круглих аватарок.
- `src/i18n/messages.js` — опис проєкту, імена, ролі, короткі підписи обома мовами.
- `src/components/SiteHeader.jsx` — спільна навігація та перемикач мови.
- `src/navigation/routes.js` — відомі сторінки та стартовий маршрут.
- `src/pages/CataloguePage.jsx` — колишній каталог з `App.jsx`, тепер окрема сторінка.

Фото скопійовані з наданих вкладень без зміни файлів. Кругла форма та наближення
задаються CSS. Фотографії постачаються разом із сайтом, без зовнішніх сервісів.
Старий логотип уже є в актуальній версії й повторно не включений у пакет.

Мінімальний супутній lint-fix у `src/lib/catalog.js`: `let comparison = 0`
замінено на `let comparison`, бо кожна гілка відразу задає значення. Це не
змінює логіку ризику, сортування чи завантаження даних.
